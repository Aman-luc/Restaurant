# 🍽 Restaurant Landing Page

A premium restaurant landing page built using HTML, CSS and JavaScript.

This project was created to showcase a modern restaurant website with an elegant design, smooth user experience and fully responsive layout.

## Live Demo

https://aman-luc.github.io/Restaurant-/

## Features

- Modern Hero Section
- Featured Food Menu
- About Restaurant Section
- Reservation Call-to-Action
- Responsive Navigation
- Beautiful Footer
- Mobile Friendly Layout
- Clean UI Design

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Goal

The objective of this project was to design a visually appealing landing page suitable for restaurants, cafés and food businesses.
